# Claude × NetSuite MCP Connector — Setup Guide

Step-by-step admin guide for connecting Claude to NetSuite via the MCP
connector: **[claude-netsuite-admin-setup-guide.pdf](claude-netsuite-admin-setup-guide.pdf)**

Covers the NetSuite-side setup (integration record, token-based auth, roles
and permissions) and the Claude-side connector configuration.

Once the connector works, see
**[netsuite-accounting-toolkit](https://github.com/tmarsteller/netsuite-accounting-toolkit)** —
Claude Code skills, SuiteScripts, and Python helpers for accounting teams on
